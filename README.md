Flood Prediction ML Project

About the Project

This project uses Machine Learning to predict flood risk based on geographical and environmental parameters.

Features

- Flood risk prediction
- Rainfall and temperature analysis
- Humidity and river discharge parameters
- Water level and elevation data
- Historical flood information

Technologies Used

- Python
- Pandas
- Machine Learning
- Flask (if used in the web application)

Project Files

- "app.py" — Main application
- "train_model.py" — Model training
- "predict.py" — Flood prediction
- "test.py" — Testing
- "dataset/" — Dataset
- "flood_model.pkl" — Trained model

How to Run

1. Clone this repository.
2. Create a Python virtual environment.
3. Install the required dependencies.
4. Run the application using "python app.py".

Disclaimer

This is an educational project. Predictions should not be used as the sole basis for real-world flood safety decisions.
